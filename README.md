# Customer Data Visualization with Python

## Project Overview
This project explores customer purchasing behaviour using Python. It uses data analysis and visualizations to identify patterns in customer distribution, age, and purchasing habits across different cities.

## Tools and Libraries
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Dataset
The illustrative dataset contains 15 customer records with the following columns:
- Customer_ID
- Age
- City
- Product
- Purchase_Amount

## Visualizations
The project includes:
1. Customer distribution by city.
2. Average purchase amount by city.
3. Customer age distribution.
4. Total purchase amount by product.

## Key Findings
- Lagos had the highest number of customers (5).
- Kano recorded the highest average purchase amount (₦11,666.67).
- Ilorin recorded the lowest average purchase amount (₦5,666.67).
- The average customer age was approximately 32 years.
- Beans generated the highest total purchase amount (₦48,500).
- Total purchases amounted to ₦136,500.

## Project File
`customer-data-visualization.ipynb`

## Limitation
The analysis uses a small illustrative dataset of 15 customers. Its findings should not be treated as representative of actual customer behaviour.
